# What's New in 1.0.1

Released 2025-10-13. **No API or runtime changes**: `src/index.js` and `src/index.d.ts` are identical to 1.0.0.
Upgrading needs no code changes.

## Changes

| Area | Change |
|------|--------|
| Dependencies | Demo dependency `marked` 16.3.0 to 16.4.0 |
| Dev dependencies | ESLint, TypeScript ESLint, Jest, Rollup, TypeScript (5.9.2 to 5.9.3), and related tools updated |
| Tooling | Added dev dependency `globals` 16.4.0 for `eslint.config.js` |

The full dependency list is in the [changelog](https://github.com/fsegurai/scrollspy/blob/main/CHANGELOG.md).
