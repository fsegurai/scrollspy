# Features

| Feature | Controlled by | Default |
|---------|---------------|---------|
| [Active section detection](active-section-detection.md) | `bottomThreshold` | always on |
| [Nested navigation](nested-navigation.md) | `nested`, `nestedClass` | off |
| [Scroll offset](scroll-offset.md) | `offset` (number) | `0` |
| [Fragment mapping](fragment-mapping.md) | `fragmentAttribute`, `navItemSelector` | `href` hash |
| [Custom events](custom-events.md) | `events` | on |
| [Dynamic content](dynamic-content.md) | `observe`, `refresh()`, `reflow` | off |
