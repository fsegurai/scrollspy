# Getting Started

Two steps get you from zero to a working scrollspy.

1. [Installation](installation.md) - add the package and pick a build format.
2. [Quick Start](quick-start.md) - wire markup, create an instance, style the active item.

## Requirements

- A browser environment with `CustomEvent` and `requestAnimationFrame`.
- `MutationObserver` only when you enable `observe: true`.
- IE11 is not supported.
